Site practices reviewed October 14, 2026

WSLI currently has no optional analytics or advertising cookies to accept. Reading this page is not consent to tracking.

Current inventory

  • WSLI cookies: none set by the current website code.
  • Local storage, session storage and persistent visitor IDs: none used by the current website code.
  • Analytics, advertising pixels and fingerprinting: none used. Canvas animations run locally for decoration; they are not used to identify visitors or transmit device measurements.
  • Fonts: served with the website, not fetched from Google.
  • Public status requests: Home and Agents fetch GitHub-hosted paper snapshots. This is a network request, not a tracking cookie; GitHub receives ordinary connection information.
  • Browser cache: your browser may cache static pages, scripts and fonts. The status request uses cache: no-store and credentials: omit. Caching files is different from assigning a visitor tracking ID.

Hosting and external sites

GitHub Pages hosts this site and logs visitor IP addresses for security. WSLI does not control GitHub’s processing or cookies on GitHub’s own sites. Visiting an external link may involve that service’s cookies and settings. See our privacy notice and GitHub’s privacy statement.

Why there is no “accept all” banner

There is no optional tracking feature to switch on in the current site. We do not add a consent cookie just to display a banner, and we do not treat scrolling or continued browsing as agreement. Browser settings can still block cookies and cross-site requests.

If optional analytics, advertising or embeds are added later, the inventory and privacy notice must be updated first. Where consent is required, those features must remain off until an informed choice, with an easy way to reject and later withdraw consent. Cookie rules depend on jurisdiction; the UK ICO guidance is one reference, not a statement that UK law is the only law that may apply.
